# 🌿 ECOVA – Platform Daur Ulang & Eco Marketplace

**ECOVA** adalah platform berbasis web yang dirancang untuk meningkatkan kesadaran dan partisipasi masyarakat dalam pengelolaan sampah melalui sistem digital yang terintegrasi.

Aplikasi ini menggabungkan konsep **recycling, reward system, dan eco marketplace** dalam satu ekosistem yang mudah digunakan dan berdampak nyata bagi lingkungan.

---

## 🚀 Fitur Utama

### ♻️ Scan & Klasifikasi Sampah

Pengguna dapat melakukan scan atau input sampah untuk mengetahui jenis dan kategori yang dapat didaur ulang.

### 🎁 Sistem Poin (Reward)

Setiap aktivitas daur ulang akan memberikan poin sebagai bentuk apresiasi terhadap kontribusi pengguna.

### 🛒 Eco Marketplace

Pengguna dapat menggunakan poin untuk mendapatkan atau membeli produk ramah lingkungan hasil daur ulang.

### 🌱 Program Tanam Pohon

Pengguna dapat menukarkan poin untuk berkontribusi dalam program penanaman pohon sebagai bentuk aksi nyata terhadap lingkungan.

### 📊 Dashboard Interaktif

Menampilkan statistik aktivitas pengguna, jumlah poin, serta dampak kontribusi terhadap lingkungan.

## 🧠 Konsep Aplikasi

ECOVA hadir sebagai solusi digital untuk:

* Mengurangi jumlah sampah melalui daur ulang
* Meningkatkan kesadaran masyarakat terhadap lingkungan
* Memberikan insentif melalui sistem reward
* Menghubungkan pengguna dengan produk ramah lingkungan

---

## 🛠️ Teknologi yang Digunakan

* **Frontend:** React.js
* **Backend:** Laravel (PHP)
* **Database:** MySQL

---

## ⚠️ Catatan

Aplikasi ini masih dalam tahap **prototype** dan menggunakan **data dummy** untuk keperluan pengembangan dan demonstrasi.

Struktur backend telah disiapkan untuk integrasi dengan data real pada tahap selanjutnya.
